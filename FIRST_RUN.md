# First-run guide (ELI5)

You installed the plugin. Now Pandamonium walks you through setup on screen. You do not have to memorize this page. Keep it if the coach was skipped.

## Step 1. Plugins

The arrow points at **Plugins** on the left. That is where add-ons live. Cursor Agents is one of those add-ons.

## Step 2. Get the Cursor key

The key is a secret string Cursor gives you.

1. Open https://cursor.com/dashboard/integrations in a browser.
2. Sign in.
3. Stay on **Integrations** (not the old Cloud Agents page).
4. Create a **User API Key**.
5. Copy it once. Treat it like a password.

Inside Cursor desktop you can also open the dashboard from the account menu, then Integrations.

## Step 3. Paste the key

The arrow points at Plugins setup. Find `CURSOR_API_KEY`. Paste. Click **Save setup**.

Pandamonium stores it in the plugin vault. Do not paste it into chat.

## Step 4. Agents button

Wait until the plugin says **Ready**. A new button appears on the left rail. Click it. That is the agent list.

If the button is missing, setup is not finished yet. Go back to step 3.

## Step 5. Talk to an agent

The sidebar lists agents. The overlay is the big chat.

- Type what you want done.
- Send.
- Wait for Composer 2.5.
- To keep working on an IDE chat inside Panda, use **fork**. Do not resume the IDE id.

That is the whole first run.
